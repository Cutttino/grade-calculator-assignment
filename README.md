Program Name:
Grade Calculator

Description:
This is a simple program that lets the user enter their grade number and the program returns the letter grade. This is one of my first programs.

Programming concepts used:
- A scanner for reading user input
- A conditional statement for different grade numbers typed in.
- Exception Handling for invalid input.

Expected Input:
- A whole number (0-100)

Expected Output:
- The letter grade and the number grade.

Edge Cases: 
- If user types in a letter for a int input the program catches the error and sends back a message without the system crashing.
- If user types a negative number the grade is returned as a F
-  Reads inputs as whole number there are no floats.
